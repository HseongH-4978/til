- 패키지
	- `go`는 패키지로 구성되며 `main` 패키지에서 시작된다.
	- 패키지명은 `import` 경로의 마지막과 같다.
- imports
	- 여러 퍠키지를 `import` 할 시 괄호로 감싸진 `factored` 임포트 문을 사용할 수 있으며, 한 줄씩 따로 작성할 수도 있지만 기본적으로 `factored` 임포트 문이 권장된다.
- Exported names
	- 대문자로 시작되는 이름만을 외부에서 참조 가능하다.
- Functions
	- 함수는 0개 이상의 매개변수를 가지며 타입은 변수의 오른쪽에 위치한다.
	- 연속하는 두 개 이상의 같은 타입을 가진 파라미터는 마지막을 제외하고 타입을 생략할 수 있다.
	- 함수의 반환값은 여러 개 일 수 있다.
	- 리턴값에 이름을 부여할 수 있으며 리턴값의 의미를 나타내는 용도로 사용되어야 한다.
	- 리턴값의 이름은 함수의 상단에 선언된 변수처럼 취급되며, 인자 없는 리턴은 이름의 값이 반환된다. 이를 `naked` 함수라 한다.
	- `naked` 함수는 가독성을 위해 짧은 함수에서만 사용한다.
- Variables
	- `var` 키워드를 사용해 변수 목록을 선언할 수 있으며 함수 매개변수와 마찬가지로 연속하는 같은 타입의 변수는 마지막을 제외하고 타입 선언을 생략할 수 있다.
	- 패키지, 함수 레벨에서 사용 가능하다.
	- 변수는 초기값을 가질 수 있으며 초기값을 가지는 경우 타입을 생략할 수 있다. 이때 변수의 타입은 초기값의 타입으로 추론된다.
	- `:=` 키워드로 간략히 표시할 수 있으며 함수 외부의 문은 키워드로 이루어져 있기 때문에 함수 외부에서는 사용할 수 없다.
- Basic types
	```go
	bool
	
	string
	
	int  int8  int16  int32  int64
	uint uint8 uint16 uint32 uint64 uintptr
	
	byte // alias for uint8
	
	rune // alias for int32
	     // represents a Unicode code point
	
	float32 float64
	
	complex64 complex128
	```
	- `int`, `uint`, `uintptr` 타입은 32 비트 시스템에서는 32비트의 크기를 64비트의 시스템에서는 64비트의 크기를 가진다.
	- 특별한 이유가 없는 경우 정수형 타입은 `int`를 사용해야 한다.
- Zero values
	- 초기값 없이 선언된 변수는 변수의 타입에 맞는 `zero` 값을 가진다.
		- 숫자: `0`
		- 문자: `""`
		- 불리언: `false`
- Type conversions
	- `T(v)`: 변수 `v`를 `T` 타입으로 변환한다.
	- c 언어와는 다르게 Go에서는 서로 다른 타입의 요소 사이의 값 할당 시 명시적인 타입 변환을 해야한다.
- Type inference
	- 타입 없이 선언된 변수는 선언의 오른쪽에 위치한 값의 타입으로 추론되며,
	  숫자 상수의 경우 값의 정밀도에 따라 `int`, `float64`, `complex128`로 추론될 수 있다.
- Constants
	- 상수는 `const` 키워드와 함께 변수 선언과 동일하게 선언할 수 있다.
	- 상수는 높은 정확도의 값을 가지며 타입없이 선언된 상수는 `context`에서 필요한 타입을 가진다.
