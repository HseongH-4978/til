1. 모든 Go 프로그램은 패키지로 구성되고 프로그램 실행은 `main` 패키지에서 시작된다. [기초 1장](https://go.dev/tour/basics/1)
	1. 패키지 이름은 임포트 경로의 마지막 요소와 같다.
2. `import` 문은 한 라인씩 여러 줄을 작성할 수도 있고 괄호로 감싸진 "그룹형" 임포 문으로 구성할 수 있다. 그룹형 임포트 사용을 권장 [기초 2장](https://go.dev/tour/basics/2)
3. 이름이 대문자로 시작하는 요소들만 패키지 외부에서 참조 가능하다. [기초 3장](https://go.dev/tour/basics/3)
4. 타입을 선언할 때는 타입이 변수 이름보다 뒤에 온다. [기초 4장](https://go.dev/tour/basics/4)
5. 두 개 이상의 매개변수의 타입이 연속될 때 마지막 매개변수를 제외한 나머지는 타입을 생략할 수 있다. [기초 5장](https://go.dev/tour/basics/5)
6. 함수는 여러 리턴을 반환할 수 있다. [기초 6장](https://go.dev/tour/basics/6)
7. 반환값에 이름을 붙일 수 있다. 이름이 붙은 반환값은 함수의 맨 위에 정의된 변수처럼 취급된다. [기초 7장](https://go.dev/tour/basics/7)
	1. 인수가 없는 `return` 문은 이름이 있는 반환값을 반환한다.(인수 없는 반환값) 가독성이 떨어질 수 있기에 짧은 함수에서만 사용한다.
8. 여러 변수를 선언할 때는 `var` 키워드를 사용한다. [기초 8장](https://go.dev/tour/basics/8)
	1. 같은 타입의 연속하는 변수 선언 시 마지막 변수에만 타입을 붙인다.
	2. 패키지 수준이나 함수 수준에 사용할 수 있다.
9. `var` 선언의 변수마다 초기값을 선언할 수 있으며, 초기값이 있으면 타입을 생략할 수 있으며, 타입은 선언한 초기값의 타입을 갖는다. [기초 9장](https://go.dev/tour/basics/9)
10. 함수 내에서는 `:=` 짧은 대입문을 통해 `var` 키워드를 생략하고 변수를 선언할 수 있다. 함수 밖에서는 불가능하다. [기초 10장](https://go.dev/tour/basics/10)
11. Go 언어의 기본 타입 [기초 11장](https://go.dev/tour/basics/11)
	1. `bool`
	2. `string`
	3. `int` `int8` `int16` `int32` `int64`
	4. `uint` `uint8` `uint16` `uint32` `uint64` `uintptr`
	5. `byte` // uint8 타입의 별칭
	6. `rune` // int32의 타입의 별칭
	       // 유니코드 코드 포인트를 나타냄
	7. `float32` `float64`
	8. `complex64` `complex128`
	9. `int` `uint` `uintptr` 타입은 32비트 시스템에서는 32비트, 64비트 시스템에서는 64비트의 너비를 가진다. 크기가 정해진 타입 선언이 아니라면 기본적으로 선언한다.
12. 초기값이 없이 선언된 변수는 해당 타입의 제로 값이 주어진다. [기초 12장](https://go.dev/tour/basics/12)
	1. 숫자 타입: 0
	2. 불리언 타입: `false`
	3. 문자열 타입:""(빈 문자열)
13. `T(v)` 형태로 값을 타입으로 감싸면 해당 타입으로 변환된다. [기초 13장](https://go.dev/tour/basics/13)
	1. 서로 다른 타입의 값을 대입하려면 명시적으로 변환해야 한다.
14. 변수 선언 시 명시적으로 타입을 지정하지 않으면 변수의 초기값으로 타입이 자동 추론된다(`var` 키워드 또는 `:=`로 변수 선언 시) [기초 14장](https://go.dev/tour/basics/14)
15. `const` 키워드를 사용해 상수를 선언할 수 있다. [기초 15장](https://go.dev/tour/basics/15)
16. 숫자 상수는 값 자체의 정밀도가 높다. (int의 범위를 벗어날 시에도 숫자 상수에는 값이 담긴다.) [기초 16장](https://go.dev/tour/basics/16)
