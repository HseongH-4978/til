- For
	- `go`에서는 유일하게 `for` 만을 이용해 반복을 수행할 수 있다.
	- 세미콜론으로 분리된 세 가지 구성 요소로 이루어진다.
		- 초기화 문: 첫 반복 전 실행
		- 조건문: 매 반복 전에 평가됨
		- Post 문: 모든 반복의 마지막에 실행
	- 초기화는 변수 선언이며, `for` scope 내에서만 유효하다.
	- bool 조건이 `false` 이면 반복을 멈춘다.
	- 다른 언어(`C`, `Java`, `JavaScript` 등)와 다르게 세 구성 요소를 괄호로 묶지 않으며 `{}`는 필수다.
	- 초기화 문과 Post 문은 생략 가능하며 이 경우 세미콜론을 생략할 수 있다. (`while` 문이 이 방식으로 표기된다.)
	- 조건을 적지 않으면 무한 루프를 돌며, 간단히 무한 루프를 표시할 수 있다.
- If
	- `for` 문과 비슷한 형태로 표현식을 괄호로 묶지 않아도 되지만 `{}`는 필수이다.
	- 조건과 변수 선언을 축약할 수 있으며, 조건 내에 선언된 변수는 `if` scope 내에서만 유효한 값이다.
	- 선언된 변수는 `else` 블록 내에서도 유효하다.
- Switch
	- `go`에서의 `switch`는 다른 언어(C, Java, JavaScript 등)와 다르게 선택된 case만 실행하고 뒤의 모든 case는 실행하지 않는다.
	  때문에 break 문이 필요하지 않다.
	- `switch case`는 상수가 아니어도 되고, 관련된 값도 정수가 아니어도 된다.
	- `switch case`는 위에서 아래로 `case`를 평가하며 `case`의 평가가 성공 시 중지한다.
	- `switch`에 값을 생략할 수 있으며 이는 `switch true`와 같다.
	  `if-else` 체인을 간략히 표시하는데 사용할 수 있다.
- Defer
	- `defer`는 함수의 실행을 주변 함수의 반환 시까지 지연시키는 함수이다.
	- 지연 호출된 함수의 인자는 즉시 평가되지만 함수의 실행은 주변 함수의 반환 시 수행된다.
	- 지연 호출된 함수는 stack에 쌓이며 주변 함수 반환 시 `last-in-first-out` 순서로 수행된다.
